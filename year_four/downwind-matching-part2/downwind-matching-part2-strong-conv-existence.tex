\section{The main steps}

For now let's use an $H^2$ - regular source term and check where it is used.

We need an existence result for the system (E-PEs): extended Primitive Equations.

    \begin{equation} \label{HNSC1-dw}    
    \partial_t u_1 + \mathbf{u} \cdot \nabla u_1 - \Delta_\nu u_1 - \gamma u_2 + \partial_1 p = 0 \text{ in } \Omega \times (0,T)
    \end{equation}
    
    \begin{equation} \label{HNSC2-dw}   
    \partial_t u_2 + \mathbf{u} \cdot \nabla u_2 - \Delta_\nu u_2 + \gamma u_1 + \partial_2 p = 0 \text{ in } \Omega \times (0,T)
    \end{equation}
    
    \begin{equation} \label{HNSC3-dw}   
    \partial_3 p = 0 \text{ in } \Omega \times (0,T)
    \end{equation}
    
    \begin{equation} \label{HNSC4-dw}   
    \nabla \cdot \mathbf{u} = 0 \text{ in } \Omega \times (0,T)
    \end{equation}
    
    \begin{equation} \label{HNSC5-dw}   
    \partial_t c + \mathbf{u} \cdot \nabla c = K_2 \partial_{22} ^ 2 c + K_3 \partial_{33} ^2 c + s \text{ in } \Omega \times (0,T)
    \end{equation}
    
Structurally, this is "almost" identical to the Primitive Equations with $T$ as a temperature, except there we have the additional connection between the $T$ function and the pressure:

    \begin{equation} \label{HNSC1-T}    
    \partial_t u_1 + \mathbf{u} \cdot \nabla u_1 - \Delta_\nu u_1 - \gamma u_2 + \partial_1 p = 0 \text{ in } \Omega \times (0,T)
    \end{equation}
    
    \begin{equation} \label{HNSC2-T}   
    \partial_t u_2 + \mathbf{u} \cdot \nabla u_2 - \Delta_\nu u_2 + \gamma u_1 + \partial_2 p = 0 \text{ in } \Omega \times (0,T)
    \end{equation}
    
    \begin{equation} \label{HNSC3-T}   
    \partial_3 p + T = 0 \text{ in } \Omega \times (0,T)
    \end{equation}
    
    \begin{equation} \label{HNSC4-T}   
    \nabla \cdot \mathbf{u} = 0 \text{ in } \Omega \times (0,T)
    \end{equation}
    
    \begin{equation} \label{HNSC5-T}   
    \partial_t T + \mathbf{u} \cdot \nabla T =  K_3 \partial_{33} ^2 T + Q \text{ in } \Omega \times (0,T)
    \end{equation}
    
We need to examine what differences the change from (\ref{HNSC3-T}) to (\ref{HNSC3-dw}) brings over the course of the proof, and what modifications are necessary in order to obtain a global existence result tailored for our version of the system.

The main difference seems to be what shows after reformulation. In C-L-T's article, (1.23),

$$ \nabla_H \bigg (\int_{-h}^z T (x,z,\xi,t ) \diff \xi \bigg) $$

appears in the horizontal momentum equation. $\nabla_H T$ is exactly the part that otherwise the convection-diffusion equation does not have information about directly.

It causes a difference (w.r.t. our case) in the application process of $\theta,$ where $u$ denotes $u = \partial_z v,$ and $ \theta = \nabla_H \cdot u + R_1 T.$ In their case this turns out to be a function definition that has full $H^2$ regularities in the sense of Proposition 5.3 and 5.4, because when the $L_1 = - \frac{1}{R_1} \Delta_H - \frac{1}{R_2} \partial_z^2$ full Laplacian and a time derivative are applied to the function $\theta$, then the horizontal temperature Laplacians from $\nabla_H \cdot u$ and $R_1 T$ cancel each other.
In more detail, $\partial_t \theta + L_1 \theta$ will contribute:

\begin{itemize}

  \item from $\partial_t \nabla_H \cdot u,$ we will have
  $$\nabla_H \cdot \nabla_H \partial_z \bigg (\int_{-h}^z T (x,z,\xi,t ) \diff \xi \bigg), $$
  
  \item from $L_1 R_1 T$ we will have
  $$ - R_1 \frac{1}{R_1} \Delta_H T,$$
  
\end{itemize}

which cancel out perfectly. This cancellation makes it possible that on p71- p72 they arrive to have only $\norm{\partial_z T}_{H^2}^2$ in the estimates, but not a full $H^3$ norm of $T$ ($\int_0^t \norm{\partial_z T}_{H^2}^2 \diff s$ is bounded, but we do not have an analogous result for the complete $H^3$ norm.)

Thus, in our case we can not keep $\theta$'s definition including the $T$ function (for their case it made sense to create $\theta$ as it would have the necessary regularities, and the momentum equation contained $T$) --- on the other hand, splitting $T$ off of $\theta$ also alters the proof significantly. The structure described on p58-p60 works in a simultaneous way for $T$ and $v.$ The general result $(4.10)$ is used later also for $T.$ If (4.10) does not include $T$ anymore, then for $T$ we need to create a solution on its own.

This suggests the following idea:

\begin{enumerate}

  \item Follow the local existence result both for the regularised system and the limit system without any major alterations (of course we need to leave out $T$ in places where it is not present, but the structure does not fundamentally change).
  
  \item As for the global existence, follow a sequential method instead of a simultaneous one:
  
  \begin{enumerate}
    \item Velocity: The global existence of the velocity function of the PEs without a temperature function has been done in Section 3 of the Strong Convergence Justification Hydrostatic article. We know that with an $H^3$ horizontal initial data $v_0$ we have the solution function $v = \mathbf{u}_h$ in $L^\infty H^3$ and in $L^2 H^4.$
    \item Concentration: using the already known velocity regularities, provide an estimate for $c.$
  \end{enumerate}

\end{enumerate}

\section{Step 1. The Regularised System with Full Diffusion}

Let's denote the "incomplete" Laplacians by $L_3, L_{23},$ representing naturally the part that is present. Let's consider

$$ \partial_t v + L_{123} v + (v \cdot \nabla_H) v - \bigg ( \int_{-h}^z \nabla_H \cdot v \bigg ) \partial_z v+ f_0 k \times v + \nabla_H p_s(x,y,t) = 0$$

$$ \nabla_H \cdot \bar{v} = 0 $$

$$ \partial_t c + L_{23} c - \epsilon \partial_{11} c + v \cdot \nabla_H c - \bigg ( \int_{-h}^z \nabla_H \cdot v \bigg ) \bigg ( \partial_z c + \frac{1}{h} \bigg).$$

The system is formally analogous to (2.1)-(2.3):

$$ \partial_t v + L_{123} v + (v \cdot \nabla_H) v - \bigg ( \int_{-h}^z \nabla_H \cdot v \bigg ) \partial_z v+ f_0 k \times v + \nabla_H \bigg ( p_s(x,y,t) -  \int_{-h}^z T \diff \xi \bigg )= 0$$

$$ \nabla_H \cdot \bar{v} = 0 $$

$$ \partial_t T + L_3 T - \epsilon \Delta_H T + v \cdot \nabla_H T - \bigg ( \int_{-h}^z \nabla_H \cdot v \bigg ) \bigg ( \partial_z T + \frac{1}{h} \bigg),$$

except we do not have the concentration term in the momentum equation. In some way it is similar to taking $T_1$ and $T_2$ in (2.1)-(2.3) instead of taking one common $T.$ In (2.1) we use $T_1 = 0,$ in (2.3) we use $T_2=c.$

The $\mathcal{F}$ map remains the same, with the modification of the left-hand side functions $A(v,T)$ and $B(v,T).$ These become $A(v), B(v)$ respectively, by leaving out the $T-$ including terms from (2.16) and (2.17). The periodicity and parity remains, and their regularities remain.

Because of the unchanged regularities and properties, the right-hand side of (2.8)-(2.11) stays $L^2_t H^2_x$ regular and we can still use the standard $L^2$ theory of linear Stokes equations and parabolic equations and have a $(U,V,\mathcal{T})$ solution.

Analogously, $D(v,T)$ will become $D(T),$ keeping only the $v$-dependent terms. The properties connecting $A(v), B(v)$ and $D(v)$ still hold.

\section{Step 3. Global existence}

The global existence of the velocity function solutions of the "basic" Primitive Equations has been shown (for "nice" boundary conditions) for example in the Strong Convergence Justification article, section 3.
Since for the case of the downwind-matching coordinate system the velocity equations are unchanged, the continuation of the unique local solution into a global one is given.

The continuation property of the $c$ local solution into a global one can be verified using the already given boundedness properties of $v.$

Since we have an $H^3$ initial data for $v_0,$ we have $L^\infty H^3$ and $L^2 H^4$ regularities for $v.$

For the $c$ function we can use the following estimates.

\subsection{$\norm{\Delta c}_2$ and $\norm{\Delta_H \partial_z c}_2$ estimates}

Let's take an arbitrary positive finite $T$ time.

Let's denote by $d$ the direction where we have \textit{diffusion}, and by $\nabla_d$ the derivatives $\partial_2, \partial_3$ (analogously as $\nabla_H$ stands for $\partial_1, \partial_2$), moreover

$$ L_d = - K_2 \partial_{22} - K_3 \partial_{33}.$$

We need

$$ \sup_{0 \leq t < T} \norm{c}_{H^2}^2 + \int_0^T \norm{\nabla_d c}_{H^2}^2 \diff t \leq B,$$

where $B=B(T)$ is a bounded $T$-dependent quantity.

We apply $\Delta$ on

\begin{equation}   
    \partial_t c + v \cdot \nabla_H c - \bigg ( \int_{-h}^z \nabla_H \cdot v \diff \xi \bigg) \bigg ( \frac{\partial c}{\partial z} + \frac{1}{h}\bigg) + L_d c = s,
\end{equation}

and multiply it by $\Delta c$ and integrate on $\Omega.$

This gives

\begin{equation}
  \begin{split}
    & \frac{1}{2} \frac{\diff}{\diff t} \norm{\Delta c}_2^2 + K \norm{\Delta \nabla_d c}_2^2 \\
    & \leq \int_\Omega \Delta s \Delta c - \Delta ( v \cdot \nabla_H c) \cdot \Delta c + \Delta \bigg ( \bigg ( \int_{-h}^z \nabla_H \cdot v \diff \xi \bigg) \bigg ( \frac{\partial c}{\partial z} + \frac{1}{h}\bigg) \bigg ) \cdot \Delta c
  \end{split}
\end{equation}

\begin{enumerate}

  \item $\int_\Omega \Delta s \Delta c \leq \norm{\Delta s}_2^2 + \norm{\Delta c}_2^2$
  
  \item Estimate for $\Delta ( v \cdot \nabla_H c) \cdot \Delta c$
  
  \item Estimate for $\Delta \bigg ( \bigg ( \int_{-h}^z \nabla_H \cdot v \diff \xi \bigg) \bigg ( \frac{\partial c}{\partial z} + \frac{1}{h}\bigg) \bigg ) \cdot \Delta c$

\end{enumerate}

\section{Questions}

\begin{itemize}

  \item on p61 they say $T^* = \infty,$ and yes, it is, but the bound under (4.13) is not finite for $T^* = \infty.$ It is true that it remains finite for any finite $T.$

  \item In the Appendix, section 5 they create bounds for the $t^2 \norm{\theta}_{H^2}^2$-type quantities, composed by polynomials and exponential functions made of $K_0,$ and $1, t,t ^2.$ But I think we don't need these bounds, we can directly use the same idea that they use as well, which is, formally:
  
  $$ \int_0^T t^2 \norm{\nabla_H v}_{H^2} \leq \int_0^T (\sup_{0 \leq t \leq T } t^2 )\norm{\nabla_H v}_{H^2} \leq T^2 \int_0^T \norm{\nabla_H v}_{H^2}$$
  
  \item What happens on p58-p59 where they increase / decrease the $t$ level? and where is (4.8) used? one: from 5.3 and 5.4 they define $\mathcal{X},$ but in (5.3) there is an $s^2$ multiplier, in $\mathcal{X}$ there isn't (decrease).on p59 they deduce from (4.1) (no $s$) and (4.4) ($s^2$) that $\int_0^{t_0^*} t \mathcal{X} \diff t \leq C.$ (one $s$!)  what is the point of these $s$ multipliers?

  \item As for the odd / even structure. It seems that this is used because for passing from $(-h, 0)$ to $(-h, h)$ we need to extend the function in a way to a domain where it did not exist before. In order to define it somehow in a way that afterwards the restriction will work as well when going backwards to $(-h, 0)$ it simply is a natural way to extend. It is natural because the odd and even properties are invariant for the system, and using symmetries we can extend the function in a way that afterwards the restriction will work for the original one. The question is, what is the benefit from passing from $(-h, 0)$ to $(-h, h).$

  \item If the (\ref{HNSC1-dw}) - (\ref{HNSC5-dw}) equations do have a unique strong solution $(v, C)$ with $(v_0, C_0)$ then taking this $v$, and combining it with the same $v_0$, and $Q = 0, T_0 = 0, T \equiv 0,$ then the resulting $(v,T) = (v,0)$ will be a solution for (\ref{HNSC1-T}) - (\ref{HNSC5-T}) with $(v_0, T_0),$ simply because by definition they satisfy the equations. Then, using the uniqueness of the solution of (\ref{HNSC1-T}) - (\ref{HNSC5-T}), it means that the only solution for this system with $T_0 = 0, Q = 0$ is $T \equiv 0.$ This is a bit surprising, because even though the source and the initial data is zero, through the velocity fluctuations the pressure changes, and with that the pressure should change too, shouldn't it?
  
  \item After all, why $p$ isn't a part of a solution as $T$ and $v$? The $T$-free hydrostatic scenario $p$ fell out due to the divergence-free condition in many places, but here it is even present in the reformulated version.

  \item We have
  
    $$\partial_z w + \nabla_H \cdot v = 0,$$
    
    $$ \partial_z p + T = 0.$$
  
  These lead to
  
    $$ w = - \int_{-h}^z \nabla_H \cdot v, $$
    
    $$ p = p_s(x,y,t) - \int_{-h}^z T .$$

The difference is that on the lower boundary we have a degree of freedom with $p,$ on the other hand for $w$ we know that on the boundary it is zero, so that part of the function is not present.

\end{itemize}
